# Another Yutto GUI

基于 Tauri 2 + Vue 3 的 Bilibili 视频下载器图形界面，为 [Yutto](https://github.com/yutto-dev/yutto) 提供GUI。

## Wayland

如果你在Wayland环境下，需要配置

```bash
export GDK_BACKEND=wayland
export WEBKIT_DISABLE_COMPOSITING_MODE=1
```
